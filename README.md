# Camiseta ZUX Expeditions — ficha de arte

Ficha de posicionamento e medidas da camiseta ZUX Expeditions, revisão v2.
Página publicada via GitHub Pages: `index.html` na raiz, sem build.

## O que a ficha traz

- Pranchas técnicas de frente, costas e manga, com o corpo em tamanho M (52 × 72 cm)
- Detalhe ampliado do peito
- Cotas de todas as estampas, em centímetros
- A restrição de sublimação que define os dois caminhos de produção
- Lista de arquivos que ainda faltam e o que está pendente de decisão

## Arte

O logo ZUX Expeditions e o snowmobile foram limpos a partir das imagens originais
(remoção de fundo e de resíduos da foto).

O UTV que aparece na prancha é **preview de avaliação** do banco de imagem
[Vecteezy id 79703961](https://www.vecteezy.com/vector-art/79703961-black-and-white-illustration-of-a-side-by-side-offroad-vehicle-with-large-tires-and-a-roll-cage-isolated-on-white-background).
A licença ainda não foi comprada — não usar em produção antes disso.

## Editar

A página é um único HTML sem dependências externas: todas as imagens estão embutidas
como data URI. Basta editar `index.html` e dar push.
